# نظام إدارة شركة توظيف سعودية (مرحلة أولى - واجهة وتشغيل أساسي)

تطبيق ويب محلي يعمل عبر المتصفح باستخدام **Python + Streamlit + SQLite**، بواجهة عربية (RTL) مرتبطة بقاعدة بيانات فعلية.

## المتطلبات
- نظام Windows
- Python 3.10+ مثبت ومضاف إلى PATH (أو استخدام مشغل `py`)

## التثبيت والتشغيل
1. افتح PowerShell داخل مجلد المشروع:
   - `C:\Company Management`
2. (اختياري لكن مستحسن) أنشئ بيئة افتراضية:
   - `py -3 -m venv .venv`
   - `.venv\Scripts\Activate.ps1`
3. ثبّت المتطلبات:
   - `py -3 -m pip install -r requirements.txt`
4. شغّل البرنامج:
   - `py -3 -m streamlit run app.py`
5. سيفتح المتصفح تلقائياً (عادة على `http://localhost:8501`).

## قاعدة البيانات
- المخطط: `database/schema.sql`
- ملف قاعدة البيانات: `database/app.db` (يُنشأ تلقائياً عند أول تشغيل إذا أمكن)
- في حال تعذر إنشاء الملف داخل مجلد `database` بسبب مسار OneDrive، سيُنشئ التطبيق ملف `app.db` في جذر المشروع تلقائياً ويستخدمه.
- البيانات محفوظة بشكل دائم في ملف SQLite ولا تُفقد عند إغلاق البرنامج.

## ما المتوفر حالياً
- **لوحة التحكم الرئيسية**: مؤشرات سريعة من قاعدة البيانات.
- **إدارة الشركات العملاء**: إضافة/تعديل/بحث/تصفية.
- **إدارة الموظفين السعوديين**: إضافة/تعديل/بحث/تصفية.
- **إدارة المتعهدين**: إضافة/تعديل/بحث/تصفية.
- **إدارة المندوبين**: إضافة/تعديل/بحث/تصفية.

> جميع الصفحات مرتبطة بقاعدة بيانات SQLite الفعلية (لا توجد بيانات ثابتة).

## ملاحظات
- لا تُعرض البيانات الحساسة (مثل الهوية/الحسابات البنكية) في جداول العرض العامة، لكنها تُخزن ضمن السجل لإدارتها.
- المراحل القادمة ستشمل: العقود والربط التشغيلي التفصيلي، الحسابات الشهرية والعمولات، التحصيلات والمدفوعات والمصروفات، التقارير المتقدمة، النسخ الاحتياطي والصلاحيات وسجل التدقيق.
- لا تدخل بيانات حقيقية أو أرقام هويات فعلية أثناء الاختبار.
