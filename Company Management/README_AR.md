# نظام إدارة شركة توظيف سعودية (مرحلة أولى - واجهة وتشغيل أساسي)

تطبيق ويب محلي يعمل عبر المتصفح باستخدام **Python + Streamlit + SQLite**، بواجهة عربية (RTL) مرتبطة بقاعدة بيانات فعلية.

## المتطلبات
- نظام Windows
- Python 3.10+ مثبت ومضاف إلى PATH (أو استخدام مشغل `py`)

## التثبيت والتشغيل
1. افتح PowerShell داخل مجلد المشروع:
   - `C:\Company Management`
2. (اختياري لكن مستحسن) أنشئ بيئة افتراضية:
   - `py -3 -m venv .venv`
   - `.venv\Scripts\Activate.ps1`
3. ثبّت المتطلبات:
   - `py -3 -m pip install -r requirements.txt`
4. شغّل البرنامج:
   - `py -3 -m streamlit run app.py`
5. سيفتح المتصفح تلقائياً (عادة على `http://localhost:8501`).

## أيقونة سطح المكتب
- بعد نسخ مجلد البرنامج إلى الكمبيوتر، شغّل `create_shortcut.bat` من داخله لإنشاء أيقونة على سطح المكتب.
- إذا نقلت مجلد البرنامج إلى مكان آخر، شغّل الأداة مرة أخرى لتحديث مسار الأيقونة.
- شغّل البرنامج من الأيقونة، واترك نافذة التشغيل مفتوحة أثناء الاستخدام.

## قاعدة البيانات
- المخطط: `database/schema.sql`
- ملف قاعدة البيانات: `database/app.db` (يُنشأ تلقائياً عند أول تشغيل إذا أمكن)
- في حال تعذر إنشاء الملف داخل مجلد `database` بسبب مسار OneDrive، سيُنشئ التطبيق ملف `app.db` في جذر المشروع تلقائياً ويستخدمه.
- البيانات محفوظة بشكل دائم في ملف SQLite ولا تُفقد عند إغلاق البرنامج.

## ما المتوفر حالياً
- **لوحة التحكم الرئيسية**: مؤشرات سريعة من قاعدة البيانات.
- **إدارة الشركات العملاء**: إضافة/تعديل/بحث/تصفية.
- **إدارة الموظفين السعوديين**: إضافة/تعديل/بحث/تصفية.
- **إدارة المتعهدين**: إضافة/تعديل/بحث/تصفية.
- **إدارة المندوبين**: إضافة/تعديل/بحث/تصفية.
- **الحركات المالية الموحدة**: تحويلات العميل، التحصيل، السداد، متابعة المستحقات والأرصدة من واجهة واحدة.

> جميع الصفحات مرتبطة بقاعدة بيانات SQLite الفعلية (لا توجد بيانات ثابتة).

## التنقل والصلاحيات والتنبيهات
- الشريط الجانبي يحتوي زرين فقط: **التسجيل** يفتح شاشة أزرار إدخال البيانات، و**العرض** يفتح شاشة أزرار لوحة التحكم والتقارير والصفحات المرتبطة بها.
- من **التسجيل** تُفتح العقود والوثائق معاً في زر واحد وتبويبين داخل الشاشة.
- الشريط العلوي ثابت أثناء التمرير ويحتوي الجرس ومساعد خدمة العملاء. زر ☰ يفتح بيانات المستخدم والإعدادات وتسجيل الخروج.
- يستطيع مدير النظام ضبط إتاحة صفحات العمل لكل دور، وإظهار أقسام التقرير أو إخفاءها.
- يمكن ضبط أنواع التنبيهات ومواعيدها من الإعدادات. أخطاء جمع التنبيهات تظهر للمستخدم وتُسجل بدلاً من تجاهلها.
- من **الإعدادات** يستطيع المدير فحص قاعدة البيانات وإعادة تهيئة مخططها دون حذف السجلات. عند تعذر فتح البرنامج، أغلق نافذته ثم شغّل `run_app.bat` مجدداً؛ وإذا ظهرت ملفات ناقصة أو تالفة، استخدم `فحص_التحديث.py` واتبع التعليمات لإعادة نسخها من إصدار سليم.
- يتضمن قسم الإعدادات **ضبط المصنع**. ينشئ نسخة أمان ثم يحذف جميع سجلات قاعدة البيانات، بما فيها الحسابات والإعدادات؛ بعده أنشئ حساب مدير جديد. تبقى نسخة الأمان والنسخ الاحتياطية محفوظة في `backups`، ويمكن استعادتها بعد إنشاء حساب المدير.
- تجربة المشروع حالياً محلية باستخدام SQLite. ربط WhatsApp/Gmail والاستضافة السحابية غير مفعّلين، ويُؤجلان إلى مرحلة لاحقة بعد التجربة المحلية وإعداد طريقة تخزين أسرار التكامل بأمان.

## ملاحظات
- لا تُعرض البيانات الحساسة (مثل الهوية/الحسابات البنكية) في جداول العرض العامة، لكنها تُخزن ضمن السجل لإدارتها.
- محرك تسجيل الحركات والسجلات التاريخية محمي من الحذف العادي؛ تُدار الحركات من الواجهة الموحدة وتنعكس على الأرصدة والتقارير.
- لا تدخل بيانات حقيقية أو أرقام هويات فعلية أثناء الاختبار.
